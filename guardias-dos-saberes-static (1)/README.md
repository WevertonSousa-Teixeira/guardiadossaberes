# Guardiãs dos Saberes — versão estática

Esta é a versão independente do site usando somente **HTML, CSS e JavaScript**. 

A estrutura é simples:

| Pasta/arquivo | Função |
|---|---|
| `index.html` | Estrutura completa do site |
| `css/style.css` | Identidade visual, layout e responsividade |
| `js/app.js` | Busca, filtros, modal, menu, toasts e áudio |
| `assets/` | Logo, hero e imagens das plantas |

Para ativar um relato oral, coloque um arquivo de áudio em `assets` e altere o campo `audio` correspondente no HTML/JavaScript. Os relatos devem ser reais, autorizados e revisados pela comunidade.

## Validação

A versão foi servida como site estático e os arquivos `index.html`, `css/style.css`, `js/app.js` e os assets visuais retornaram HTTP 200. O navegador carregou o hero, o catálogo e as imagens locais.
